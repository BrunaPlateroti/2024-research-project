# Functional Map of GPCRs, G-Protein, TFs

**Author:** Bruna Plateroti

### Overview 
This is an R project
This repository contains the analysis and results from my Master’s research project, which systematically investigates
the regulatory relationships between G-protein coupled receptors (GPCRs), small G-proteins, and transcription factors 
(TFs) in cancer cells. Leveraging gene dependency data from the Cancer Dependency Map (DepMap), this project aims to 
uncover critical genes and pathways implicated in cancer progression, focusing on the Ras signalling pathway and serotonin
receptors (HTRs).

### Features 
* Functional Pathway Inference Analysis (FPIA)
* Integration of Gene Dependency Data from DepMap
* Statical Analysis:Pearson's correlation, hierarchical clustering
* Pathway and Enrichment Analysis
* Output Figures highlighting key findings
